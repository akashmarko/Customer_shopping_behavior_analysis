# Customer Shopping Behavior Analysis

This project analyzes transactional data from 3,900 customer purchases using **Python**, **PostgreSQL**, and **Power BI** to uncover insights into spending patterns, product preferences, and demographics.

*For the complete detailed methodology, data cleaning steps, and full query outputs, refer to the **Customer Shopping Behavior Analysis.pdf**.*

# 📊 Project Overview & Stack

* **Python (pandas):** Cleaned data, handled 37 missing ratings, and standardized columns.


* **PostgreSQL:** Loaded cleaned data to run business-driven relational queries.


* **Power BI:** Built an interactive dashboard tracking KPIs like average purchase amount ($59.76) and rating (3.75).



## 📈 Key Findings

* **Gender & Age:** Male customers drove higher total revenue than females ($157.890 vs $75,191), with Young Adults being the highest-earning age group.


* **Subscriptions:** 73% of customers are non-subscribers, yet their average purchase amount ($59.87) matches subscribers ($59.49).


* **Products:** Accessories and Clothing are top categories, led by Jewelry and Blouses. Hats and Sneakers rely most heavily on discounts.


* **Segmentation:** The customer base is highly stable, with 3,116 users classified as "Loyal".



## 🚀 Strategic Recommendations

* **Convert Non-Subscribers:** Launch exclusive perks targeting the 73% non-subscriber base to capitalize on their high average spend.


* **Optimize Discounts:** Review pricing strategies for discount-dependent items (e.g., hats, sneakers) to protect profit margins.


* **Targeted Marketing:** Focus promotional campaigns on top-rated products and the high-revenue Young Adult demographic.
